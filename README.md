# Dream Biker (Hanif)

Official workspace for the **Dream Biker** digital platform.

The frontend is located in the [`dream-biker-frontend`](./dream-biker-frontend) directory.

## Quick Start

```bash
cd dream-biker-frontend
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Quality Checks

```bash
cd dream-biker-frontend
npm run lint
npx tsc --noEmit
npm run build
```
